# Moon Games

こどもと一緒に遊ぶ、7つのゲームです。

[ゲームを開く](https://lgtm868.github.io/moon-phase-game/)

- **つき**: 月の満ち欠けとクイズ。見つけた16種類を図鑑に保存。
- **ぴあの**: 曲に合わせて演奏。自分のメロディーを20秒まで録音・再生。
- **さんすう**: 20体のスプランキーと5・10・20までの足し算と引き算。キャラをタップして自分で引くモードも。
- **あてっこ**: 20体の名前から絵を選ぶ5問。段階的なヒントと20人のコレクション。
- **バイバイン**: 倍増を観察し、大きさを比較。次の数を予想する絵のクイズも。
- **ごはん**: 3難易度・1000問。正解した食べ物を50種類の図鑑に保存。
- **えいご**: 3カテゴリ・18語の発音と5問クイズ。最後に覚えた言葉を聞いて復習。

全ゲームで上部の切り替えバーを共有します。iPad横向きではブラウザの
表示領域に合わせて、問題・回答・主な操作を1画面に配置しています。
曲一覧や長い説明は、画面内の閉じられるパネルで開きます。

公開URLの `?game=moon` を `piano`・`addition`・`guess`・`baibain`・`food`・`english`
へ変えると、各ゲームを直接開けます。ログインは不要です。

ローカルでは `index.html` を開きます。各HTML、`games-theme.css`、
`games-theme.js`、`sprunki-roster.js`、キャラクター画像、`sounds/` を同じ配置で保持してください。
バイバインには `baibain-model.js` と `baibain-renderer.js` も必要です。
ごはんクイズには `food-quiz-bank.js` も必要です。
共通メニューには `game-navigation.js` と `game-navigation.css` を使います。
共通音声には `games-audio.js`、`games-audio-controls.js`、
`games-audio-controls.css` が必要です。曲を使うゲームには
`games-audio-manifest.js` と `sounds/packed/` も同じ配置で保持してください。
ランキングには `games-ranking.js`・`games-ranking.css`・`games-ranking-config.js`
を使います。オンラインへの記録送信は、本人が投稿ボタンを押したときだけです。
月・ごはんの図鑑は同じブラウザ内に保存します。保存できない設定でも、その回は遊べます。

## 音声

音楽・効果音・声の音量を、各ゲームの設定ボタンから調節できます。
合奏は共通の音声時計を使い、追加したキャラが次の小節から参加します。
画面を離れたときは停止し、戻るだけでは再生を再開しません。

19曲を同じ周期の候補ループとして整えています。Blackは周期未確定のため、
約17.46秒の原音を最後まで1回再生します。合奏中は次の小節から参加し、
ほかのキャラのループを止めずに終了します。ピアノでも音がONの状態で
Blackを選ぶと1回再生します。
元の音源は保持しています。波形・同期の検証は音源の真正性や聴感上の
完成を保証するものではありません。

## 追加キャラクター

月のゲームは35体、ピアノは25体から選択できます。既存の20体とは別に、
PyramixedのACID・Tox・Sulfur、RetakeのMard・Mr. BearをMOD表示付きで追加しています。
追加5体には未検証の音源を割り当てていません。ピアノの鍵盤音はキャラ固有の原曲ではありません。
さんすう・あてっこの出題は従来の20体のままです。
アンパンマン系10体のイラストは参考資料を見て生成したもので、公式配布画像ではありません。

アンパンマン系10体には、このゲーム用に作曲したオリジナルの合奏パートを追加しています。
公式の主題歌・キャラクターソングではありません。各パートは100 BPM・8拍・4.8秒で、
既存の共通音声時計に合わせて次の小節から参加します。複数選択・消音・画面離脱時の停止に対応します。
音色と楽譜は `tools/anpanman-score.cjs`、音源の生成手順は `AUDIO-ASSETS.md` を参照してください。
金管・リード・弦・オルゴールの主旋律に、控えめな低音、和音、打楽器と掛け合いを加えています。
公式の曲名・キャラソングの存在は [VAPの作品情報](https://store.vap.co.jp/syousai.asp?item=VPCG-83569) を参照しましたが、公式音源の使用や原曲の再現を意味しません。

月の「すすむ」・月のタップ・矢印操作は、代表名の16段階に途中の日を補った36段階を巡ります。
1回の移動は1日分以内です。新月・上弦・満月・下弦などの基準位置を飛ばさず、
通常は短いアニメーションでつなぎます。動きを減らす設定では即時表示します。
月名一覧からの直接選択は維持します。途中の月も「ねまちづき」「ふけまちづき」「にじゅうろくや」などの呼び名を表示し、固有名を割り当てていない日は「よっかめのつき」のように区別します。
暦の日付を指定しないモデルなので、これらは月齢からの目安です。実際の旧暦日付や正確な満月時刻とは区別し、上弦・満月・下弦の基準位置とクイズの形の判定は変更していません。
呼び名の参考: [月の満ち欠けと呼び名](https://koyomi8.com/reki_doc/doc_0203.html)。
