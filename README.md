# おつきさまのかたち

3歳向けの月の満ち欠けゲームです。

月の画面の「さんすう」から、スプランキーの足し算・引き算ゲームへ移動できます。上の「つき」で月に戻れます。
算数は5まで・10まで・20までの3段階で、正解後に自動で次へ進みます。「おんがくを ながす」でキャラクターの音楽も楽しめます。
同じ入口からピアノ・あてっこも選べます。ログインは不要です。

公開URL: https://lgtm868.github.io/moon-phase-game/

月の画面の「あてっこ」から、4歳向けのひらがな名前当てでも遊べます。
読み上げとおてほん付きの3択・5問で、何度でもやり直せます。
あてっこへ直接: https://lgtm868.github.io/moon-phase-game/?game=guess
